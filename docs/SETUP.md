# Final channel integration steps

Canonical GitHub repository: https://github.com/ndrorchestration/AI-From-Zero-With-Ender

## Pin on GitHub

1. Open https://github.com/ndrorchestration
2. In the profile's **Popular repositories** / **Pinned** section choose **Customize your pins**.
3. Select `AI-From-Zero-With-Ender` (GitHub permits at most six pins). If all slots are occupied, choose which existing pin to replace, then save.

This changes the profile layout, not repository visibility. The main profile README already links to this repository.

## Add to YouTube Studio

1. Open https://studio.youtube.com and select **Customization**.
2. Find **Profile** (or the current links section) and add a link titled **GitHub — AI From Zero With Ender**.
3. Enter https://github.com/ndrorchestration/AI-From-Zero-With-Ender and publish the channel customization.
4. Where useful, add the same repository URL to existing video descriptions. Review each video individually; do not overwrite existing descriptions.

## Publishing a new episode

1. Add verified title, publication date and URL to `episodes/README.md` and the root README.
2. Copy `episodes/EPISODE_TEMPLATE.md` into a numbered episode file and fill only verified fields.
3. Add teaching examples and licensed graphics, linking rather than duplicating large media.
4. Record Studio measurements in `analytics/snapshots.csv` with exact start/end dates, and keep blanks for missing metrics.
5. Separate corrections and retrospective metrics from content claims.
